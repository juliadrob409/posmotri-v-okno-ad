# Посмотри в окно

## Доработка CSS

В рамках работы над визуальным оформлением страницы были выполнены следующие изменения:


- Настроено центрирование основного содержимого страницы с помощью Flexbox.
- Создана двухколоночная структура страницы и настроены расстояния между основными блоками.
- Заданы размеры видеоблока и настроено отображение видео с помощью `object-fit: cover`.
- Скорректированы расположение и выравнивание элементов поисковой формы.
- Настроены размеры полей ввода, флажков и кнопок.
- Добавлены эффекты взаимодействия с элементами: наведение курсора, нажатие и фокус.
- Настроены шрифты, размеры, начертание и расположение заголовков и текстовых элементов.
- Оформлена боковая панель со списком видеокарточек.
- Настроены размеры миниатюр видео и отображение текстовых описаний.
- Добавлена вертикальная прокрутка списка видеокарточек.
- Разработан пользовательский скроллбар с помощью CSS.
- Добавлено визуальное выделение выбранной видеокарточки и настроены состояния ссылок.
